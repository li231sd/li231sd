# Hi, I'm Sahil

I build things that mix software, hardware, and a bit of aerospace. Mostly that means robots, computer vision, embedded stuff, and anything that flies.

I'd rather build a thing myself than treat it as a black box, so I tend to write the software, design the parts, and train the models on my own, even when it takes longer.

## What I work with

- **Languages:** Python, Java, C++, JavaScript
- **Vision / ML:** OpenCV, TensorFlow, MediaPipe
- **Hardware:** Raspberry Pi, Arduino, sensors
- **Design:** CAD, 3D printing

## What's in here

Robotics, automation, vision, embedded, and aviation projects. Some are finished, a lot are half-working prototypes or experiments I built to figure something out.
